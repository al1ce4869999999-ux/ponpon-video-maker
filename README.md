# ぽんぽん動画メーカー — v0.5 2Dリグ開発版

> **公開中のmainはv0.4です。** この文書のv0.5機能は作業ブランチ `feat/v05-2d-rig` にあり、iPhone Safari実機テストと映像品質受入が完了するまで本番公開しません。

## v0.5で追加された機能（開発ブランチ）

- body / head / eye / mouth / ear / arm / tail / prop などの画像パーツを登録し、親子関係・pivot・位置・回転・倍率・表示順・透明度を管理できます。
- Canvas上のタッチドラッグと数値入力によるリグ編集、表情差分、9つのモーションと3つの複合モーションを利用できます。
- カットごとにリグと表情・モーションを指定し、プレビューや動画録画へ接続します。
- 既存v0.1〜v0.4作品の読み込み互換を意図した移行処理があります。ただしSafari実機での最終確認は未完了です。
- 画像パーツは端末内処理で登録します。単一のイラストからパーツを自動抽出する機能は**ありません**。

### リグ素材の登録
1. 分割済みの透過PNG / WebPを用意し、リグ編集で「＋たぬき」または「＋人間」を選択します。
2. body、head、目、口、耳、しっぽ等のパーツへ画像を登録します。頭の下に目・口を配置すると頭の回転に追従します。
3. 親、位置、pivot、表示順を調整して、モーション確認で動きを点検します。
4. 絵コンテでリグを選び、プレビューを確認します。従来の静止画像モードも残ります。

## v0.4 の説明（本番で利用できるバージョン）


Zetaなどから物語を貼り付けると、**ブラウザ内のルールベース解析**で物語をカットに分解し、動作・構図・演出を選ぶ無料のWebアプリです。外部のAI API、APIキー、GPUサーバー、課金は不要です。

公開URL: https://al1ce4869999999-ux.github.io/ponpon-video-maker/

## v0.4 で変わったこと

- `analyzer.js` に独立した解析エンジンを実装（依存ライブラリなし）
- Zetaの `*地の文*`、裸の台詞、括弧内の心の声、名前付き台詞を区別
- 動作を **試み・失敗・反応・転倒・移動・観察・静止** などに分類
- 連続する文章の重要度を考慮し、最大12カットへ順序を維持して圧縮
- 動作ごとに、モーション・構図・長さ・切り替え・漫画効果を設定
- 話者を断定できない時は空欄にする（「ぽんぽん」と勝手に決めない）
- コマごとの**解析の根拠・要確認事項**、全体の行動シーケンスを表示
- 既存v0.1～0.3の作品データを再解析なしで引き継ぐ。手動編集も可能

## iPhone Safari の使い方

1. 公開URLを開く。
2. ぽんぽんの人間／たぬき姿の正式なイラストを登録する。
3. シーンの文章を貼り、「場面を解析して絵コンテ作成」を押す。
4. 「02 · 絵コンテ」で各カットの「解析の根拠を見る」を開き、構図・話者・動作などを調整する。
5. 「03 · 動画プレビュー」で動きを確認し、書き出す（Safariの録画機能の対応状況による）。
6. 「04 · 作品管理」からJSONバックアップができる。

**書き出しは端末で実時間録画**するので、録画中はSafariを閉じたりロックしたりしないでください。

## 精度・安全上の制約

- 今回の「解析」は高度な生成AIではなく、明示的な日本語のルール判定。誤認・見落としは起こります。特に省略された話者や曖昧な心理は確定できません。
- 根拠レベルは**ルール上の目安**で、統計的な予測確率ではありません。
- 画像の再描画・新ポーズ生成・口パク・手足・しっぽの部分アニメは**未実装**。現在の2Dモーションは画像全体に適用されます。
- 効果音テキストは音声ではありません。BGMも自動生成しません。
- 最大12カット。入力が非常に長いと最初の18,000文字／160ブロックに制限します（画面に警告を表示）。
- 作品は端末内のIndexedDBに保存。サーバーにアップロードしません。Safariデータ消去に備えてJSONバックアップしてください。
- GitHub Pagesの公開ソースコードは誰でも閲覧可能ですが、ユーザーがブラウザで入力した文章や画像はリポジトリに含まれません。
- GitHub Pagesで動かすため、HTMLと隣接する `analyzer.js` が必要です。ZIP版もこの2ファイルを含みます。

## テスト

```bash
node test_analyzer_v04.js
python test_v04.py
```

`test_analyzer_v04.js` はルールの10件の回帰テスト。`test_v04.py` はChromiumでの画面操作、6カットの編集、解析レポート、JSON復元、短いMP4の録画などを検証します。**iPhone Safari実機での録画と保存は未検証**です。

## 次の品質向上の課題

APIなしでキャラを本当に動かすには、イラストの透明背景化、顔／耳／しっぽ／腕などのレイヤー素材の登録、関節位置の指定、2Dリグによる変形が必要です。解析エンジンの動作語を、将来そのリグの「しっぽを振る」「手を伸ばす」などのモーションへつなぎます。**単一画像から必ず正しい新ポーズを生成できるものではありません。**
