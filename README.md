# ぽんぽん動画メーカー｜Ponpon Studio v0.3

Zetaの物語を貼り付け、登録したぽんぽんのイラストを使って動く漫画を作る無料のWebアプリです。外部動画生成APIは使わず、ブラウザのCanvasでレンダリングします。

**公開先:** https://al1ce4869999999-ux.github.io/ponpon-video-maker/

## iPhoneでの使い方

1. Safariでアプリを開き、Zetaの文章を貼り付ける。
2. 人間姿・たぬき姿の正式なイラストを登録する。
3. 「絵コンテを自動作成」→ 最大12カットに分割。
4. カットごとに構図、モーション、漫画効果、字幕、話者名、吹き出し位置、切り替えを編集。
5. プレビュー後、全編またはPART別に動画を書き出す（iPhoneの録画機能の対応による）。
6. 作品管理でJSON形式のバックアップを保存できる。

## v0.3 で追加した機能

- **カット間トランジション**：なし／暗転／コマめくり／横スライド／白フラッシュ
- **漫画エフェクト**：スピード線／集中線／網点トーン／衝撃線
- **話者別の吹き出し**：話者名と左・右・自動の表示位置
- **PART分割動画**：20秒目安でカット境界に分け、指定したPARTだけを個別に書き出す
- **旧データ引き継ぎ**：公開版v0.1のIndexedDBを維持し、必要に応じてv0.2保存領域も読み込む

## 制限・注意

- 現在は静止画像全体への2Dアニメーションです。耳・しっぽ・口・目・手足を個別に動かす機能はまだありません。
- 自動カット割り・感情・構図の推定はルールベースで、AIによる画像生成や高度な文章理解は未実装です。
- **オノマトペは文字演出のみ**。本当の効果音やBGMは入りません。
- iPhone SafariでのMP4/MediaRecorder書き出しはOSの実機確認が必要です。非対応の場合でもプレビューや静止画保存は使えます。
- 端末内に画像・文章が保存され、GitHubには送信されません。Safariのデータ消去に備え、JSONバックアップをおすすめします。
- GitHub Pagesのソースコードは公開されます。
- 外部API料金0円、ビルド不要、moco.やのののリポジトリとは分離。
