# ぽんぽん動画メーカー｜Ponpon Studio

Zetaの文章を貼り付け、手持ちのぽんぽんのイラストを使って動く漫画風動画を作る無料のWebアプリ（試作版 v0.1）です。**有料の動画生成AI/APIは使いません。**

## 使い方（iPhone Safari）
1. WebアプリをSafariで開き、「シーン入力」にZetaの文章を貼り付ける。
2. ぽんぽんの人間形態・たぬき形態の正式なイラストを登録する。
3. 「絵コンテを自動作成」を押す。最大12カットまで。
4. カットごとに画像・字幕・形態・動き・表示時間を修正する。
5. 「動画プレビュー」で確認し、「動画を書き出す」または「画像を保存」を使用する。
6. 大事なデータは「作品管理」からJSONバックアップを保存する。

## 機能
- 文章を簡易ルールで分割して絵コンテにする（AIによる意味解析ではありません）
- 人間／たぬき形態と背景画像の登録
- カット別の画像・動き・字幕・秒数・順序の編集
- 浮遊・ジャンプ・震え・左右揺れ・ズーム・移動・静止、7種類の2Dモーション
- 縦9:16・正方形1:1・横16:9
- Canvas動画プレビュー、PNG保存、対応ブラウザでの動画書き出し
- IndexedDBで端末に保存、画像を含むJSONのインポート／エクスポート

## 動作上の注意
- 動画生成AIではなく、**既存の静止画全体を動かす**仕組みです。耳、しっぽ、目などのパーツを自動的に独立アニメーション化する機能は未実装です。
- iPhone SafariでのMediaRecorder録画／MP4書き出しは実機未検証です。非対応の場合はPNG保存を利用してください。
- 自動カット割りは文章の区切りを使う簡易版。登場人物や感情の正確な認識は保証しません。
- 動画出力は端末内で実時間録画します。録画中はSafariを閉じたり画面をロックしないでください。
- 素材・プロジェクトは端末内に保存され、アプリから外部送信されません。Safariのデータ消去で消える可能性があります。
- 有料APIや外部クラウドDBを使わず、単一HTMLだけで動作します。
